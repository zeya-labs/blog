# 代理工具安装配置

这里按使用场景记录代理工具选择：桌面端用图形客户端，服务器端用命令行安装脚本，Android 端用移动客户端。

## 桌面端：clash-verge-rev

项目地址：[clash-verge-rev/clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev)

下载地址：[Releases · clash-verge-rev/clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)

## 服务器端：nelvko/clash-for-linux-install

项目地址：[nelvko/clash-for-linux-install](https://github.com/nelvko/clash-for-linux-install)

```bash
git clone --branch master --depth 1 https://gh-proxy.org/https://github.com/nelvko/clash-for-linux-install.git \
  && cd clash-for-linux-install \
  && bash install.sh
```

相关文档：[Usage](https://github.com/nelvko/clash-for-linux-install/wiki)
